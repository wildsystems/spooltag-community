# SpoolTag Manager community

Community of [SpoolTag Manager](https://spooltag.eu): a network spool station for 3D printing
filament. A scale, an NFC reader/writer and a web interface, connected directly to
[Spoolman](https://github.com/Donkie/Spoolman).

This repository holds no code. Everything happens in
[Discussions](https://github.com/wildsystems/spooltag-community/discussions).

## Where to post

| Category | For |
|----------|-----|
| Announcements | News about the project (posted by the maintainers) |
| Q&A | Questions and problems; mark the answer that helped |
| Ideas | Tag formats, printer integrations and features you would like |
| Polls | Short polls about printers, tags and setups |
| Show and tell | Your spool storage, printer farm or station setup |
| General | Everything else |

## Stay up to date

Sign up for occasional e-mail updates at [spooltag.eu](https://spooltag.eu/#updates).

## Code of conduct

Be kind and stay on topic. This community follows the
[Contributor Covenant](CODE_OF_CONDUCT.md); report problems to news@spooltag.eu.
